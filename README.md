# 🚀 Criando uma Aplicação em Go com Testes

Este repositório contém os exemplos e códigos desenvolvidos durante a seção **Criando uma Aplicação** do guia [Aprenda Go com Testes](https://larien.gitbook.io/aprenda-go-com-testes/criando-uma-aplicacao/introducao).

A proposta dessa parte do estudo é construir uma aplicação mais completa utilizando princípios de TDD (Test-Driven Development), cobrindo conceitos como design orientado por testes, armazenamento em memória e em arquivos, HTTP handlers, rotas, persistência e muito mais.

## ▶️ Executando os testes

Para rodar os testes e acompanhar o desenvolvimento da aplicação, basta executar:

```bash
go test
```

## 🎯 Objetivo

O objetivo é entender como construir aplicações idiomáticas em Go com testes automatizados desde o início, com foco em:

- TDD na prática
- Separação de responsabilidades
- Interfaces para abstração de dependências
- Manipulação de arquivos e armazenamento de dados
- HTTP servers e rotas com `net/http`
